## 1. 项目概述

### 1.1 一句话定位
面向 **TIC（Testing, Inspection, Certification）行业** 的实时数据分析平台，向客户、外部用户及全行业公司提供数据可视化与监控能力。

### 1.2 目标用户
| 用户类型 | 占比预期 | 核心诉求 |
|---------|---------|---------|
| **客户** | 50% | 查看自己送检/认证的进度、结果、趋势 |
| **外部用户** | 30% | 浏览行业整体数据、市场报告 |
| **全行业公司** | 20% | 对标、调研、决策支持 |

### 1.3 业务价值
- **客户侧**: 透明化检测/认证进度，提升信任
- **外部**: 行业洞察入口，建立品牌权威
- **公司**: 数据资产变现入口（MVP 不考虑变现，但留口子）

## 3. 用户故事

### US-1: 数据浏览
> 作为 **客户**，我希望打开网站就能看到 TIC 行业最新数据概览，**以便**快速了解当前市场动态。

**验收标准**:
- 首屏加载 < 3 秒
- 至少展示 3 类核心指标（检测量、认证通过率、行业分布）
- 数据有更新时间戳

### US-2: 维度筛选
> 作为 **外部用户**，我希望按时间/类别筛选数据，**以便**聚焦我关心的细分领域。

**验收标准**:
- 时间筛选：今日 / 7天 / 30天 / 自定义
- 类别筛选：Testing / Inspection / Certification
- 筛选后图表实时更新

### US-3: 自动刷新
> 作为 **全行业公司**的用户，我希望页面数据自动更新，**以便**无需手动刷新就能看到最新值。

**验收标准**:
- 每 5 分钟自动拉取
- 顶部显示"最后更新于 XX:XX"
- 加载状态平滑过渡

## 4. 功能需求

### 4.1 仪表盘布局
```
┌─────────────────────────────────────────────────┐
│  Header (Logo + 语言切换 + 最后更新时间)         │
├─────────────────────────────────────────────────┤
│  筛选器: [时间] [类别] [区域]                     │
├─────────────────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐           │
│  │ KPI1 │ │ KPI2 │ │ KPI3 │ │ KPI4 │           │
│  └──────┘ └──────┘ └──────┘ └──────┘           │
├─────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐             │
│  │ 趋势折线图     │  │ 类别饼图       │            │
│  └──────────────┘  └──────────────┘             │
├─────────────────────────────────────────────────┤
│  ┌──────────────────────────────────┐           │
│  │  地区分布地图 / 柱状图             │           │
│  └──────────────────────────────────┘           │
└─────────────────────────────────────────────────┘
```

### 4.2 KPI 卡片（暂定 4 个）
1. **今日检测总量** (Number + 同比箭头)
2. **认证通过率** (百分比 + 环形图)
3. **在检项目数** (Number + 趋势)
4. **平均交付天数** (Number + 行业基准对比)

### 4.3 性能指标
| 指标 | 目标 |
|------|------|
| 首屏加载 (FCP) | < 1.5s |
| API 响应 (P95) | < 300ms |
| 数据刷新间隔 | 5min |
| 并发用户 | 100 (MVP) |
